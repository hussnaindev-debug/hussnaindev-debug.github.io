The game

Fall for Brainrot is a Roblox progression game in development. The loop is built around an upgrade economy: players earn currency and spend it on rarity-tiered items that grant stacking bonuses, then rebirth to push further. I'm designing and building every system myself.

Upgrades are tiered by rarity, from Common up to Legendary, and each tier grants bonuses to earnings, luck, and strength, so choosing what to buy and when is the core decision. A rebirth system and quests sit on top to give the game long-term goals.

A rarity-tiered upgrade economy

The core system is an upgrade economy where the items players buy are tiered by rarity. A Common upgrade has no bonuses; Rare, Epic, and Legendary tiers each stack larger multipliers for earnings, luck, and strength. That turns every purchase into a decision about which stat to invest in and when.

On top of the shop sit a rebirth system and quests that give the game its long-term pull. It's all built server-authoritative so the economy can't be manipulated from the client. The game is in development, with more systems and content planned as it grows.

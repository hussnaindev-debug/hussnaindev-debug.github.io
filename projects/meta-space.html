Overview

Meta-Space: Pioneering Education in the Metaverse was my final year project at UET Peshawar — an immersive virtual classroom designed to mirror real classroom workflows in a 3D space. Built in Unreal Engine 4, it uses MetaHuman avatars to give participants presence and the Agora SDK for real-time voice communication and file sharing.

The experience includes interactive whiteboards and collaboration tools so educators can teach naturally inside the metaverse. We conducted user testing with educators and iterated on usability, performance, and learning outcomes — work that was ultimately published in the IJIST journal.

Key Features

🧑‍🏫 Virtual Classroom

An immersive 3D classroom in Unreal Engine 4 mirroring real teaching workflows.

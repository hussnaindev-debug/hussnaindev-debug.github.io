The game

Mouse Maze is a WebGL game built in Unity and published on itch.io, so it runs right in the browser with no download. You play as a mouse navigating a maze, working through the corridors to find the cheese at the end.

The part I'm most proud of is the control system. The game detects the player's device and enables the right scheme automatically: keyboard controls on desktop, and a responsive on-screen joystick on touch devices. The same WebGL build feels natural on a laptop or a phone, with no setup from the player.

The interface is built to feel alive, with menus, buttons, and panels animated in DOTween, so every interaction has smooth motion and polish rather than hard cuts.

One build, every device

Shipping a single WebGL build that plays well on both a laptop and a phone is the core engineering story of Mouse Maze. Rather than ask the player to pick a mode, the game detects the device at runtime and enables the right control scheme automatically.

On desktop that means keyboard controls; on touch devices it's a responsive on-screen joystick. The result is that the same build feels native in either context with zero setup. Layered on top, DOTween drives the menus, buttons, and panel transitions so the interface feels responsive and finished rather than static.
